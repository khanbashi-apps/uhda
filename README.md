# عُهدة · Uhda

وثائقك وضماناتك وصيانة سياراتك وأجهزتك في مكان واحد، مع تنبيه تلقائي يوم الموعد. عربي وإنجليزي، نهاري وليلي، خط المراعي، ويعمل بدون إنترنت.

إعداد: **أحمد الخنبشي** · AHMED ALKHANBASHI

الإصدار الحالي: **v1.0**

## الروابط المباشرة

| النسخة | الرابط |

## التثبيت خطوة بخطوة

1. **الويب على الآيفون:** افتح رابط الصفحة في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية». بعد أول فتح يعمل بدون إنترنت، والتنبيهات تعمل من iOS 16.4 فأحدث.
2. **أندرويد:** افتح رابط APK من الجوال ← نزّل ← اسمح بالتثبيت من مصادر غير معروفة ← ثبّت.
3. **آيفون IPA:** نزّل الملف من الرابط ← افتحه في تطبيق التوقيع ← وقّعه ← ثبّته.

## الإصدار 1.0

- قسمان: **سياراتي** (القطع والصيانة، ووثائق السيارة) و**وثائقي وأجهزتي** (الوثائق الشخصية والأجهزة).
- زر **+** في منتصف الشريط السفلي يضيف حسب مكانك: قطعة أو صيانة، وثيقة سيارة، أو «ماذا تريد أن تضيف؟». الزر العلوي للوضع النهاري/الليلي.
- **تنبيه تلقائي** يوم انتهاء الوثيقة أو موعد الصيانة، ويتكرر كل يوم حتى «تم التجديد / تم التغيير / تمت الصيانة» أو «إسكات التنبيه». انتهاء الضمان: تنبيه واحد.
- **السجل والفواتير:** كل تجديد أو صيانة يُحفظ بتاريخه وتكلفته وصورة فاتورته، والفواتير القديمة تبقى. السجل للاطلاع فقط، والحذف برسالة تأكيد.
- **ممشى السيارة:** عند التغيير تختار آخر قراءة مسجلة أو تسجّل قراءة جديدة.
- صفحة العنصر فيها زر «حفظ» برسالة «تأكيد التغيير»، وكل حذف أو تعديل يسأل قبل التنفيذ.
- أيقونات تلقائية للأشياء الشائعة: الزيت، الإطارات، البطارية، الفرامل، الفلتر، الهاتف، المكيف، الغسالة، الثلاجة، الجواز والرخصة وغيرها.
- نسخة احتياطية مشفّرة `.uhda` (حفظ في… / مشاركة) واسترجاع، وتقرير PDF.
- شاشة البداية المتحركة، ترحيب وإعداد سريع عند أول فتح، والبيانات محفوظة في الجهاز.

## كيف يُبنى

- مصدر التصميم: `src/Uhda.dc.html` (نفس ملف لوحة النماذج).
- `scripts/build-web.mjs` يحوّله إلى `index.html` و`app.js`، ويشغّله `dc-runtime.js` مع Preact، ويحفظ البيانات في الجهاز.
- `sw.js`: عمل بدون إنترنت، وفتح العنصر عند الضغط على التنبيه، وفحص يومي في الخلفية على أندرويد.
- داخل APK / IPA تُستخدم التنبيهات المحلية (`@capacitor/local-notifications`).
- مع كل تحديث على `main` يبني GitHub Actions ملفات APK وIPA ونسخة الويب، وينشرها في **Releases** باسم `v1.0`.
