# عُهدة · Uhda

وثائقك وضماناتك وصيانة سياراتك وأجهزتك في مكان واحد: سياراتي (القطع، الوثائق، الوقود)، وثائقي وأجهزتي، والمصاريف. عربي وإنجليزي، نهاري وليلي، خط المراعي، ويعمل بدون إنترنت.

الإصدار الحالي: **v1.0**

## الروابط المباشرة

| النسخة | الرابط |
|---|---|
| صفحة الويب (تعمل بدون نت بعد أول فتح) | https://khanbashi-apps.github.io/uhda/ |
| أندرويد APK | https://github.com/khanbashi-apps/uhda/releases/latest/download/Uhda.apk |
| آيفون IPA (بدون توقيع) | https://github.com/khanbashi-apps/uhda/releases/latest/download/Uhda-unsigned.ipa |
| نسخة الويب كاملة (ZIP) | https://github.com/khanbashi-apps/uhda/releases/latest/download/Uhda-web-offline.zip |

## التثبيت خطوة بخطوة

1. **الويب على الآيفون:** افتح رابط الصفحة في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية». بعد أول فتح يعمل بدون إنترنت.
2. **أندرويد:** افتح رابط APK من الجوال ← نزّل ← اسمح بالتثبيت من مصادر غير معروفة ← ثبّت.
3. **آيفون IPA:** نزّل الملف من الرابط ← افتحه في تطبيق التوقيع ← وقّعه ← ثبّته.

## كيف يُبنى

- مصدر التصميم: `src/Uhda.dc.html` (نفس ملف لوحة النماذج).
- `scripts/build-web.mjs` يحوّله إلى `index.html` و`app.js`، ويشغّله `dc-runtime.js` مع Preact، ويحفظ البيانات في الجهاز.
- مع كل تحديث على `main` يبني GitHub Actions ملفات APK وIPA ونسخة الويب، وينشرها في **Releases**، وسجلات البناء في فرع `build-logs`.

## الإصدار 1.0

- شاشة البداية المتحركة: الشعار في منتصف الشاشة، ثم ثانيتان.
- عند أول فتح: ترحيب (اللغة والمظهر، أو استرجاع نسخة احتياطية) ثم إعداد سريع من 3 خطوات: سيارتك، وثائقك وتواريخ انتهائها، والتذكيرات.
- يبدأ التطبيق فارغاً، والبيانات محفوظة في الجهاز.
- الشعار ورقم الإصدار في الإعدادات ← «حول التطبيق».
- لا تكبير بالضغط المتكرر ولا تحديد للنص.
